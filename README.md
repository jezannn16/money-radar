# Money Radar

Локальный журнал расходов с точной десятичной арифметикой, персональными бюджетами и безопасным импортом выписок. Файлы выписок обрабатываются локально, без отправки в LLM или сторонний сервис.

## Реализовано

- `add`, отчёт по месяцу, месячный бюджет, CSV export и удаление всех локальных данных пользователя.
- Импорт CSV/XLSX: mapping колонок, preview, построчные ошибки, явное подтверждение `--confirm`, batch id и защита повторного импорта.
- Дедупликация по external ID (если источник/external ID совпадает) или fingerprint из даты, суммы, валюты и merchant. Одна сумма не считается достаточным признаком дубля.
- Курсы CBR через официальный XML интерфейс для дневных/исторических запросов с timeout и внутрипроцессным cache.
- Опциональный Telegram-ввод `/add кофе 350 RUB` с preview и подтверждением inline; месячный отчёт и установка бюджета. Bot access is restricted to `ALLOWED_USER_IDS`.
- У каждого запроса в CLI указан `--user`, SQLite фильтрует записи по user ID.

## Запуск

Python 3.11+; создать окружение и установить пакет:

```sh
uv venv --python 3.12
uv pip install -e '.[dev]'
uv run money-radar --help
```

Чтобы запустить Telegram интерфейс, задайте `TELEGRAM_BOT_TOKEN` и comma-separated `ALLOWED_USER_IDS` в `.env`, затем выполните `uv run money-radar-bot`. Токен не передавайте в чат и не сохраняйте в Git.

Пример:

```sh
uv run money-radar add 350 RUB coffee --category Food --user 42
uv run money-radar budget 2026-10 Food 10000 RUB --user 42
uv run money-radar month 2026-10 --user 42
uv run money-radar import statement.csv --user 42 --map date=Date --map amount=Amount --map currency=Currency --map merchant=Merchant --map category=Category
```

Сначала команда `import` печатает preview и ничего не меняет; только `--confirm` фиксирует импорт. Для CSV ожидается UTF-8, для XLSX — первый лист. Сумма расхода положительная, валюта — ISO alpha-3, округление до копеек применяется `ROUND_HALF_EVEN`. Разные валюты в отчёте не суммируются.

Исторические курсы запрашиваются у официальных XML интерфейсов Банка России: [описание XML](https://www.cbr.ru/development/sxml/). Идентификатор валюты берётся из XML ответа Банка России, затем запрашивается диапазон, равный нужной дате. Текущий курс никогда не используется как подстановка для отсутствующего исторического значения.

## Ограничения

CLI не является системой аутентификации: используйте локальную базу только на доверенном компьютере. Подтверждённый Telegram ввод сохраняет дату поступления, отдельного выбора даты/категории ботом пока нет. XLSX требует openpyxl. Если CBR не публиковал валюту на дату, команда сообщит об отсутствии данных. Recurring rules пока только зарезервированы в схеме; нет автоматического расписания и резервного копирования.
